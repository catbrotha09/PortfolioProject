# Mi portafolio con Flask

Plantilla simple para armar tu portafolio en una clase.

## Cómo correrlo

```
pip install flask
python main.py
```

Abre http://127.0.0.1:5000

## Qué hay en cada archivo

| Archivo | Para qué sirve |
|---|---|
| `main.py` | Python (Flask): recibe la habilidad que eliges y la manda a la página |
| `templates/index.html` | El contenido de la página (busca los comentarios ✏️ Paso 1 al 8) |
| `static/css/style.css` | Colores y diseño (empieza cambiando los colores de arriba) |
| `static/img/` | Tus imágenes |

## Ruta sugerida (40 min)

1. Pasos 1–5 del HTML: tu nombre, foto y sobre mí.
2. Cambia los 4 colores de `:root` en el CSS.
3. Pasos 6–7: tus propias habilidades y proyecto.
4. Paso 8: contacto.
5. Reto: agrega una tarjeta nueva copiando una `.card`.
